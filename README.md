# xvpn

Свой VPN на Xray-core с Telegram-ботом и мини-аппом. Не зависит ни от чьих токенов: Xray ставится официальным скриптом XTLS, весь остальной код лежит в этом архиве.

## Что поднимается на каждом сервере

| Протокол | Как идёт трафик | Зачем |
|---|---|---|
| VLESS + XHTTP + TLS | клиент → Cloudflare → ваш сервер | основной: IP сервера скрыт за CDN, трафик похож на обычный HTTPS |
| VLESS + Reality + Vision | клиент → IP сервера:443 | резерв: самый быстрый, не зависит от Cloudflare |
| VLESS + XHTTP + Reality | клиент → IP сервера:443 | резерв: XHTTP без CDN |

Все три протокола работают на порту 443: nginx разводит подключения по SNI.

## Подготовка в Cloudflare (для каждого сервера)

1. DNS → A-запись `vpn.ваш-домен` → IP сервера, **Proxied** (оранжевое облако).
2. SSL/TLS → Overview → **Full (strict)**.
3. SSL/TLS → Origin Server → **Create Certificate** на 15 лет. Сертификат и ключ установщик попросит вставить.
4. Network → **gRPC: On** (нужно для потокового режима XHTTP; без него клиент сам переключится на packet-up).

Для второго сервера нужен свой поддомен, например `nl.ваш-домен`.

## Установка (Ubuntu 22.04/24.04, root)

**Главный сервер** (Xray + бот + панель):
```bash
bash <(curl -fsSL https://raw.githubusercontent.com/duboshin52/xvpn/main/install.sh) panel
```
Установщик спросит домен, SNI для Reality, сертификат, токен бота (от @BotFather) и ваш Telegram ID (узнать у @userinfobot). Потом откройте бота, нажмите /start → «Открыть панель».

**Дополнительный сервер**:
```bash
bash <(curl -fsSL https://raw.githubusercontent.com/duboshin52/xvpn/main/install.sh) node
```
В конце установщик выведет URL агента и секрет. Их нужно вставить в мини-апп: «Серверы» → «Добавить». Повторно показать эти данные: `bash /opt/xvpn/src/install.sh info`.

**Обновление** (код, Xray, зависимости): та же команда с `update` вместо `panel`.

**Без вопросов**: ответы можно передать переменными, например `DOMAIN=vpn.site.ru BOT_TOKEN=... OWNER_ID=... CERT_FILE=/root/cert.pem KEY_FILE=/root/key.pem bash <(curl ...) panel`.

## Мини-апп

- **Статус**: CPU, RAM, диск, сеть, аптайм, состояние Xray на каждом сервере, перезапуск Xray, число онлайн-ключей, общий трафик.
- **Ключи**: создать ключ с лимитом ГБ и сроком; продлить, сбросить трафик, выключить, перевыпустить, удалить. У каждого ключа есть QR-код и ссылка-подписка, отдельные vless-ссылки тоже доступны.
- **Серверы**: добавить, удалить, скрыть сервер из подписок. Это может только владелец.
- **Админы**: владелец добавляет и убирает админов по Telegram ID. Админ управляет ключами, но не серверами и не другими админами.

Ключи, у которых кончился срок или лимит трафика, отключаются автоматически раз в минуту. Админы получают уведомление об этом, а также о падении и восстановлении серверов.

## Бот

`/start`, `/status`, `/keys`, `/newkey имя [дней] [ГБ]`, `/admins`, `/addadmin ID [имя]`, `/deladmin ID`, `/id`.

## Подписка

Одна ссылка на ключ содержит все серверы и все три протокола. Она работает в Happ, Hiddify, v2rayN и v2RayTun. Клиенты, которые это поддерживают, показывают остаток трафика и срок действия.

## Советы против обрывов

- По умолчанию используйте XHTTP-CDN. Если Cloudflare в вашем регионе тормозит, переключайтесь на Reality.
- В качестве SNI для Reality берите сайт с TLS 1.3 и HTTP/2, который хостится рядом с вашим VPS (та же страна или провайдер). Проверить сайт: `xray tls ping сайт.com`. Сменить SNI: отредактируйте `/etc/xvpn/node.env` и выполните команду установки с `update`. Ключи сохранятся. Затем в панели: «Серверы» → «Обновить параметры».
- Установщик включает BBR.

## Где что лежит

- `/etc/xvpn/`: настройки, сертификат и секреты (`node.env`, `panel.env`).
- `/opt/xvpn/agent/`: агент ноды. `/opt/xvpn/panel/`: панель, бот и база `xvpn.db` (её стоит бэкапить).
- Сервисы: `xray`, `xvpn-agent`, `xvpn-panel`, `nginx`. Логи: `journalctl -u xvpn-panel -f`.
